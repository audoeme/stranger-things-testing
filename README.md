## **⚡ Tecnologias usadas**

- HTML/CSS (Landing Page)
- JavaScript e Typescript (Playwright)
- Node.js e npm
- Playwright Test Runner
- VS Code (opcional com workspace configurado)

---

## **🚀 Pré-requisitos**

- Node.js v16+ instalado
- npm (Node Package Manager)
- VS Code recomendado para edição
- Navegadores Chrome/Edge/Firefox/Safari para testes

---

## 📝 Casos de teste automatizados

- Botão Hero: clicar em "Começar a Explorar" e verificar alert.
- Hover nos cards das temporadas: validar efeito hover (levitar + sombra).
- Newsletter válida: preencher formulário e verificar envio com alert.
- Newsletter inválida: tentar enviar sem preencher campos obrigatórios.
- Rolagem da página: clicar nos links do menu e verificar se a rolagem vai para a seção correta e até o final da página.
